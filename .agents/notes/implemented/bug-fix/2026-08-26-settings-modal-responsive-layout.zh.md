# Agent Note: Settings modal responsive layout

Status: implemented

[English](2026-08-26-settings-modal-responsive-layout.md) | 中文

## Problem

Settings 对话框在内容列旁固定保留 188px 的导航栏。视口变窄后，剩余列宽不足以容纳偏好说明、提供方操作和模型控件。Flex 项目会把中文压缩成一字一行，操作标签也会换行或互相重叠。

## Decision

`@deepseek-ai/dsh-client-ui-settings-general` 用一个共享标题栏渲染标题、可选的文档操作和关闭控件。桌面端保留 188px 导航栏与可滚动内容列；视口宽度不超过 640px 时，面板使用安全区内的可用宽度，把导航移到标题栏下方并改成可横向滚动的导航行，内容列占据剩余高度。

归具体功能所有的偏好行在断点以上保持桌面布局。窄面板中，说明与选择器改为纵向排列，移除桌面专用的文字内缩，并保持选择器标签单行显示。外观选项改为可用的多列换行布局。

模型设置让提供方身份与操作保持在同一组，禁止按钮标签换行，并在窄面板中把模型字段排到图标操作之前。插件标签页与 Agent 预设卡片采用同一套受宽度约束的横向滚动或单列布局。

断点全部写在所属 CSS Modules 中。布局不新增视口 store，不改变设置状态所有权，也不改变设置 slot 契约。

## Alternatives considered

**在移动端继续保留桌面导航栏并缩小它。** 否决，因为导航栏仍会占用说明文字和提供方控件所需的空间，在更窄视口中仍会出现同类问题。

**让所有偏好行保持横排，只增加 `overflow-wrap`。** 否决，因为选择器和操作控件仍会与文字争夺空间，控件标签换行也会降低扫描和触控的可用性。

**创建独立的移动端设置路由。** 否决，因为这会为纯展示差异复制 slot 投影、关闭行为和分区生命周期。

## Consequences

桌面设置保留原有导航栏、共享设置分区和滚动归属。窄屏设置通过顶部导航行展示全部分区；分区较多时只在导航行内横向滚动，不会撑宽对话框。功能行在移动端会变高，因此选项列仍是唯一的纵向滚动区域。不需要运行时或 wire 变更。
